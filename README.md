# Tools Website

A collection of pure **HTML + JavaScript tools**. No installations, no build tools, no servers, just open the HTML file and start using them. Also avalible at https://tools.gavin.cloud

## Features

- Lightweight and fast
- Pure **HTML + JavaScript**
- Works offline after downloading
- Easy to navigate interface
- Multiple useful **wtools** in one place

## Getting Started

1. **Download or clone the repository**:

   ```bash
   git clone https://github.com/GavinEke/tools.git
   ```

2. Open the website:

Simply open index.html in your preferred web browser.

> ⚠️ No server is required. Everything runs locally. Each tool is self-contained and fully functional in the browser.

## Usage

1. Open index.html.
2. Navigate through the menu to select a web tool.
3. Use the tool directly in your browser—no internet connection needed after the first load (excluding those that use an external API).
